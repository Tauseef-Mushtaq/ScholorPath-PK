# ScholarPath PK — Development Modules

Each module is one focused AI coding session whenever practical. Do not skip dependencies.

## Module 01 — Foundation

Next.js, TypeScript, Tailwind, shadcn/ui, basic structure, Supabase client, environment handling, Git setup.

Done when the application runs and the Supabase connection is configured safely.

## Module 02 — Authentication

Signup, login, logout, password reset, sessions, protected routes, roles.

## Module 03 — Database + Security

Core schema, migrations, indexes, RLS, role authorization and storage foundations.

## Module 04 — Landing + Public Pages

Landing page, navigation, footer, public country browsing, public scholarships and public mentor stories.

## Module 05 — Student Profile

Personal, education, academic, experience, research, English, preferences and goals.

## Module 06 — Document Vault

Private upload, storage policies, categories, preview, delete, metadata and basic processing status.

## Module 07 — Scholarship Data

Admin CRUD and initial curated/verified scholarship dataset. Start small: roughly 100–300 high-quality opportunities rather than trying to cover the whole internet.

## Module 08 — Search + Filters

Country, degree, funding, field, IELTS, GPA, deadline and university filtering.

## Module 09 — Eligibility + Matching

Rules engine and profile fit scoring. Strong Match / Possible Match / Not Eligible.

## Module 10 — Scholarship Details + Sources

Complete detail page, funding breakdown, requirements, dates, official URLs, last verified date and Pakistan-side section.

## Module 11 — RAG Knowledge Base

Source ingestion, extraction, chunking, embeddings, pgvector, metadata and retrieval.

## Module 12 — RAG Assistant

Scholarship-scoped Q&A using retrieved official evidence, citations/source display and refusal when evidence is insufficient.

## Module 13 — Agentic Scholarship Assistant

Agent orchestrator, tool calling, goal-based plans, roadmap updates, document checks and approval gates.

## Module 14 — Application Workspace

Applications, tasks, documents, notes, statuses, timelines and deadlines.

## Module 15 — Application Copilot

SOP, essays, motivation letter, research proposal, CV and application question assistance.

## Module 16 — Application Review

Consistency checker, completeness checker and final application health check.

## Module 17 — Mentor Community

Mentor application, verification, stories, timelines, Q&A and mentor matching.

## Module 18 — Admin + Production Hardening

Admin dashboard, moderation, scholarship/source/RAG management, monitoring, security tests, performance and deployment hardening.

## Dependency Order

01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11 → 12 → 13 → 14 → 15 → 16 → 17 → 18

## Module Rule

A session should work ONLY on its assigned module. If unfinished, leave a handoff for the next session to continue the same module.
